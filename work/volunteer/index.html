SELECTED WORK / 04 — TRUST BUILDING

讓志工社群的影響力被看見，
重新建立參與者的信任與認同。

從分散的志工招募資訊出發，重新梳理品牌形象、參與方式與社群故事，讓訪客先理解這個社群的價值，再找到適合自己的參與方式。

品牌形象與網站改版資訊架構互動體驗設計個人／企業雙受眾
HERO / FINAL DESIGN▧新版網站全貌／精選畫面建議使用新版首屏與關鍵區塊的組合圖，避免直接放過長的全頁截圖
01 / THE CHALLENGE

從「介紹可以加入什麼」，
轉向「先讓人理解為什麼值得參與」。

舊版以不同志工服務與招募資訊為主要內容，社群理念、活動與合作成果分散在不同區塊。隨著網站目標轉向形象建立，這次改版需要重新安排內容優先順序，同時保留活動宣傳與加入入口。

01 / POSITIONING重新建立社群形象

讓理念、影響力與專業累積成為訪客的第一印象。

02 / AUDIENCE整理兩種參與入口

兼顧個人與企業參與者，清楚呈現各自可投入的服務。

03 / COMMUNITY呈現真實社群連結

透過活動紀錄與資深成員，讓社群不只停留在文字介紹。

舊版來源為 Wayback 歷史存檔，部分圖片未完整保存；比較重點為可辨識的資訊結構與內容順序。

02 / BRAND EXPRESSION

先讓影響力成為第一印象，再談加入。

以符合社群形象的識別符號建立視覺記憶點，並將影響力數據、獲獎紀錄放在前段，優先傳達社群累積的成果與專業價值。

設計重點｜將「我們做過什麼、產生什麼影響」放在「如何加入」之前，重新建立品牌敘事的順序。
VISUAL 01▧品牌首屏＋影響力數據展示識別符號、成果數字、獎項跑馬燈；廣告素材不作為網頁內容策略的證據
03 / INFORMATION ARCHITECTURE

讓個人與企業，各自找到適合的參與方式。

根據專案掌握的受眾資訊，個人參與者較常透過網站了解服務，因此將個人參與資訊優先呈現，並透過 Tab 切換整合企業參與內容。每項服務提供獨立加入入口，減少訪客找到目標後還需要重新搜尋的步驟。

受眾行為依專案當時掌握的資訊規劃；尚未將其描述為經量化驗證的研究結論。

04 / COMMUNITY EXPERIENCE

讓活動紀錄不只是照片列表，而是可探索的參與經驗。

考量活躍參與者的使用習慣，採用接近社群限時動態的分類與輪播形式，整理不同活動的影像，讓大量紀錄更有瀏覽節奏，也傳達社群真實的交流氛圍。

設計重點｜透過熟悉的互動語言，將活動分類、照片與文字說明整合成可探索的內容。
VISUAL 04 / INTERACTION▧活動分類＋照片輪播優先使用完整照片影格或短影片；Wayback 缺圖部分以示意標註
VISUAL 05 / PEOPLE▧前輩人物群像＋成員卡片展示真實人物如何融入背景，搭配前輩介紹與分類
05 / SOCIAL PROOF

讓真實人物，成為社群專業與信任的證據。

將具代表性的資深成員照片組合為頁面背景，搭配人物介紹卡片，透過群像呈現社群的人脈、經驗與傳承，讓訪客不用閱讀大量介紹，也能感受到社群的規模與專業。

設計重點｜讓人物素材成為品牌敘事的一部分，而不只是名單展示。
DESIGN OUTCOME / CASE SUMMARY

讓社群的價值被理解，
讓參與成為自然的下一步。

這次改版將原本分散的志工資訊，整理成以影響力、參與價值、服務入口與真實社群為主軸的網站敘事。從內容優先順序到互動形式，每個設計決策都回應了形象建立與分眾參與的需求。

目前呈現的是設計策略與交付內容；實際招募成效或品牌認知成效待取得資料後補充。
